# Comet Seal House frontend concept

Independent visual preview. The current client and server are not imported, changed, or connected by this demo.

Open index.html directly in a browser. It needs no install or build. The Home, Products, and About Us views use hash navigation and work from a local file.

The catalogue includes eight fictional products with search, category filtering, sorting, details, and a simulated enquiry modal. Nothing is sent or persisted.

All model names, specifications, and product illustrations are fictional. Business location is reused from the existing website; proposed copy is not a claim of verified capabilities.

Assets: assets/comet.svg and assets/hero.png are copies of existing project assets. assets/products.png was generated using the built-in image_gen tool. It is displayed as four illustrations from a two-by-two contact sheet. The original application assets are untouched.

Generation prompt: Create a premium industrial product photography contact sheet with exactly four individual sealing products, arranged in a perfectly even 2 by 2 grid on an actually transparent background. Each object sits fully inside its own quadrant with generous equal margins; no object crosses quadrant boundaries. Top left: a polished stainless steel mechanical seal with visible black rubber base, three-quarter view. Top right: a dark graphite carbon seal ring with a thick stepped edge, three-quarter view. Bottom left: a compact water pump seal with silver metal flange, black rubber bellows and a short metal spring, three-quarter view. Bottom right: a black rubber automotive oil seal with small copper-colored inner lip, three-quarter view. Crisp catalog studio photography, precise machined edges, soft controlled lighting, physically believable materials. All four objects comparable visual size. Square canvas. No text, no labels, no numbers, no logos, no watermarks, no dividers, no frames, no background, no floor. Illustrative fictional demo products for a seal supplier website.
